## Firma del método

```ts
list(
  params?: ListParams<NumberingRangeFilters>,
  options?: RequestOptions,
): Promise<ApiResponse<PaginatedData<NumberingRange>>>
```

## Endpoint Factus

`GET /v2/numbering-ranges`

Fuente oficial: [Listar rangos](https://developers.factus.com.co/rangos-de-numeracion/facturacion/obtener-rangos)

## Ejemplo

```ts
const response = await factus.numberingRanges.list({
  filter: { is_active: "1" },
  page: 1,
  per_page: 10,
});

const numberingRanges = response.data.data;
const pagination = response.data.pagination;
```

## Rangos eliminados

```ts
const deleted = await factus.numberingRanges.list({
  filter: { trashed: "only" },
});

for await (const range of factus.numberingRanges.listAll({ trashed: "with" })) {
  console.log(range.id, range.deleted_at);
}
```

`deleted_at` es `null` para un rango no eliminado y contiene una fecha para uno eliminado. Esto es independiente de `is_active`: un rango inactivo no necesariamente está eliminado. Puedes [restaurar un rango eliminado](/docs/modules/numbering-ranges/facturacion/restore) usando su ID.
