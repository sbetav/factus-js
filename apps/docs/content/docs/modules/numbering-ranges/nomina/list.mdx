---
title: Obtener rangos
description: Listar rangos de numeración de nómina con filtros y paginación.
---

## Firma del método

```ts
list(
  params?: ListParams<PayrollNumberingRangeFilters>,
  options?: RequestOptions,
): Promise<ApiResponse<PaginatedData<PayrollNumberingRange>>>
```

## Endpoint Factus

`GET /v2/numbering-ranges/payrolls`

Fuente oficial: [Listar](https://developers.factus.com.co/rangos-de-numeracion/nomina/obtener-rangos)

## Ejemplo

```ts
const response = await factus.numberingRanges.payrolls.list({
  filter: { is_enabled: true },
  page: 1,
  per_page: 10,
});

const ranges = response.data.data;
```
