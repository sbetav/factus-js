---
title: Ver nómina de eliminación
description: Obtener el detalle de una nómina de eliminación por su número consecutivo.
---

## Firma del método

```ts
get(
  number: string,
  options?: RequestOptions,
): Promise<ViewAdjustmentPayrollResponse>
```

## Endpoint Factus

`GET /v2/adjustment-payrolls/{number}`

Fuente oficial: [Ver nómina de eliminación](https://developers.factus.com.co/nota-ajuste-nomina/ver)

`data.payroll` trae la nómina referenciada (número, trabajador y CUNE). El borrado sigue usando `reference_code`.

## Parámetros

<TypeTable
  type={{
    number: {
      type: "string",
      required: true,
      description:
        "Número consecutivo de la nómina de eliminación (por ejemplo, NADJ1).",
    },
  }}
/>

## Ejemplo

```ts
const response = await factus.adjustmentPayrolls.get("NADJ1");
console.log(response.data.number, response.data.payroll?.number);
```
