## Firma del método

```ts
list(
  params?: ListParams<AdjustmentPayrollFilters>,
  options?: RequestOptions,
): Promise<GetAdjustmentPayrollsResponse>
```

## Endpoint Factus

`GET /v2/adjustment-payrolls`

Fuente oficial: [Listar nóminas de eliminación](https://developers.factus.com.co/nota-ajuste-nomina/listar)

## Ejemplo

```ts

  filter: { number: "NEF110" },
  page: 1,
  per_page: 10,
});

const notes = response.data.data;
```
