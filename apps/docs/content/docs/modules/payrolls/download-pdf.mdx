---
title: Descargar PDF
description: Descargar el PDF de una nómina electrónica en Base64.
---

## Firma del método

```ts
downloadPdf(
  number: string,
  options?: RequestOptions,
): Promise<DownloadPayrollPdfResponse>
```

## Endpoint Factus

`GET /v2/payrolls/{number}/download-pdf`

Fuente oficial: [Descargar PDF](https://developers.factus.com.co/nomina/descargar-pdf)

## Parámetros

<TypeTable
  type={{
    number: {
      type: "string",
      required: true,
      description: "Número de la nómina cuyo PDF se descargará.",
    },
  }}
/>

## Ejemplo

```ts
const response = await factus.payrolls.downloadPdf("990000070");
const pdfBuffer = Buffer.from(response.data.pdf_base_64_encoded, "base64");
```

## Ejemplo de respuesta

```json
{
  "status": "OK",
  "message": "Solicitud exitosa",
  "data": {
    "file_name": "[PAYROLL_FILE_NAME]",
    "pdf_base_64_encoded": "[BASE64_PDF]"
  }
}
```
