## Firma del método

```ts
list(
  params?: ListParams<PayrollFilters>,
  options?: RequestOptions,
): Promise<GetPayrollsResponse>
```

## Endpoint Factus

`GET /v2/payrolls`

Fuente oficial: [Listar nóminas](https://developers.factus.com.co/nomina/listar)

## Ejemplo

```ts
const response = await factus.payrolls.list({
  filter: { identification_number: "1234567890" },
  page: 1,
  per_page: 10,
});

const payrolls = response.data.data;
const pagination = response.data.pagination;
```
