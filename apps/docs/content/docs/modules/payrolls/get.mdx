## Firma del método

```ts
get(
  referenceCode: string,
  options?: RequestOptions,
): Promise<ViewPayrollResponse>
```

## Endpoint Factus

`GET /v2/payrolls/reference/{reference_code}`

Fuente oficial: [Ver nómina](https://developers.factus.com.co/nomina/ver)

```ts
const response = await factus.payrolls.get("990000070");
```
