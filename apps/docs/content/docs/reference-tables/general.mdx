## Tipo de documento de factura (`BillDocumentCode`)

```ts
import { BillDocumentCode, BillDocumentCodeInfo } from "factus-js";

const code = BillDocumentCode.ElectronicSalesInvoice;

console.log(code); // "01"
console.log(BillDocumentCodeInfo[code].description); // "Factura electronica de venta."
```

| Clave                          | Valor  | Descripción                                       |
| ------------------------------ | ------ | ------------------------------------------------- |
| `ElectronicSalesInvoice`       | `"01"` | Factura electrónica de venta.                     |
| `ElectronicTransmissionType03` | `"03"` | Instrumento electrónico de transmisión - tipo 03. |
