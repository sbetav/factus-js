Catálogos de referencia para el módulo de nómina (`factus.payrolls`).

Fuente oficial:
[Tablas de referencia nómina](https://developers.factus.com.co/tablas-de-referencia/tablas-referencia-nomina)

## Periodo de nómina (`PayrollPeriodCode`)

```ts
import { PayrollPeriodCode, PayrollPeriodCodeInfo } from "factus-js";

const code = PayrollPeriodCode.Monthly;

console.log(code); // "5"
console.log(PayrollPeriodCodeInfo[code].description); // "Mensual"
```

| Clave      | Valor | Descripción |
| ---------- | ----- | ----------- |
| `Biweekly` | `"4"` | Quincenal   |
| `Monthly`  | `"5"` | Mensual     |

| ---------- | ----- | ----------- |

## Tipos de devengados y deducciones

Constantes para los campos `accrual_type_code` / `deduction_type_code` dentro de los bloques `accruals` y `deductions`. Cada una expone su mapa `*Info` con la descripción oficial.

| Constante SDK                          | Campo API típico              | Valores                                                                        |
| -------------------------------------- | ----------------------------- | ------------------------------------------------------------------------------ |
| `PayrollSeveranceTypeCode`             | `accruals.cesa.*`             | `1` Cesantías, `2` Intereses a cesantías                                       |
| `PayrollPremiumTypeCode`               | `accruals.prim`               | `1` Primas, `2` Primas no salariales                                           |
| `PayrollIncentiveTypeCode`             | `accruals.boni.*`             | `1` Bonificación, `2` Bonificación no salarial                                 |
| `PayrollEpctvBonusTypeCode`            | `accruals.bono.*`             | `1`–`4` Pagos salariales / no salariales / alimentación                        |
| `PayrollTransportAllowanceTypeCode`    | `accruals.tra.*`              | `1`–`3` Auxilio transporte y viáticos                                          |
| `PayrollCompensationTypeCode`          | `accruals.comp.*`             | `1` Ordinarias, `2` Extraordinarias                                            |
| `PayrollOtherConceptTypeCode`          | `accruals.otro.*`             | `1` Salarial, `2` No salarial                                                  |
| `PayrollLeaveTypeCode`                 | `accruals.lice.*`             | `1` Maternidad/paternidad, `2` Licencia remunerada, `3` Licencia no remunerada |
| `PayrollVacationTypeCode`              | `accruals.vaca.*`             | `1` Comunes, `2` Compensadas                                                   |
| `PayrollIncapacityTypeCode`            | `accruals.inca.*`             | `1` Común, `2` Profesional, `3` Laboral                                        |
| `PayrollAllowanceTypeCode`             | `accruals.auxi.*`             | `1` Salarial, `2` No salarial                                                  |
| `PayrollOvertimeTypeCode`              | `accruals.hora.*`             | `1`–`7` Horas extra y recargos                                                 |
| `PayrollPensionSolidarityFundTypeCode` | deducciones fondo solidaridad | `1` Solidaridad pensional, `2` Subsistencia                                    |
| `PayrollSanctionTypeCode`              | `deductions.sanc.*`           | `1` Pública, `2` Privada                                                       |
